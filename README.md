Passei várias horas desenvolvendo, testando e tentando fazer tudo funcionar. Na monitoria de hoje, a Ana Damasceno acompanhou algumas das minhas dificuldades e me ajudou a entender melhor como utilizar as plataformas. Agora entendi melhor como deveria ter feito e vou conseguir organizar esse processo corretamente nas próximas atividades. Só gostaria de pedir que a falta desse histórico no GitHub não fosse interpretada como cópia ou uso de IA para fazer o trabalho, porque realmente desenvolvi o código passo a passo. Foi uma confusão minha com as ferramentas, e não com a forma como fiz a atividade.
